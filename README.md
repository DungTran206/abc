# Paradise Nursery Shopping Application

Welcome to the Paradise Nursery online plant shop! This is a dynamic e-commerce web application built using React and Redux. 

## Features
* **Landing Page:** A welcoming intro page to get started.
* **Product Listing:** Browse 18 unique houseplants categorized into Air Purifying, Pet Friendly, and Succulents.
* **Shopping Cart:** Add plants to your cart, dynamically update quantities, remove items, and view total costs.
* **State Management:** Utilizes Redux Toolkit for seamless cart state management across components.
